Module 1: Comprehensive Study Notes

1. Random Variables (Discrete & Continuous)

A random variable is a rule or function that assigns a numerical value to each outcome of a random experiment.

  • Discrete Random Variable: Takes countable, distinct values (e.g., number of packet errors in a transmission, coin tosses). Represented by a Probability Mass Function (PMF) $P(X = x)$.
  • Continuous Random Variable: Takes any value within a continuous interval (e.g., signal voltage, noise amplitude, time to failure). Represented by a Probability Density Function (PDF) $f(x)$.

2. Probability Density Function (PDF) & Cumulative Distribution Function (CDF)

  • PDF ($f(x)$): Represents the relative likelihood of a random variable taking a given value. The total area under the PDF curve is always equal to 1 ($\int_{-\infty}^{\infty} f(x)dx = 1$).
  • CDF ($F(x)$): Represents the probability that the random variable $X$ takes a value less than or equal to $x$ ($F(x) = P(X \le x) = \int_{-\infty}^{x} f(t)dt$). The CDF is a non-decreasing function ranging from 0 to 1.

3. Standard Probability Distributions

  • Binomial Distribution: Models discrete success/failure trials (e.g., bit error testing in digital comms). Formula: $P(X=x) = ^nC_x p^x q^{n-x}$. Mean = $np$, Variance = $npq$.
  • Poisson Distribution: Models rare events occurring over a fixed interval (e.g., number of incoming calls at a switchboard per minute). Formula: $P(X=x) = \frac{e^{-\lambda} \lambda^x}{x!}$. Mean = Variance = $\lambda$.
  • Normal (Gaussian) Distribution: The most important continuous distribution in engineering, characterized by a bell-shaped curve. Symmetric about mean $\mu$. Formula: $f(x) = \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$.
  • Exponential Distribution: Frequently used in reliability and queuing theory to model time between independent events. Formula: $f(x) = \lambda e^{-\lambda x}$ for $x \ge 0$.

4. Joint Probability Distributions

When two random variables $X$ and $Y$ are studied simultaneously, we use Joint PMF / PDF $f(x,y)$.

  • Marginal Distributions: Extracting the probability distribution of a single variable by summing or integrating out the other variable.
  • Independence: $X$ and $Y$ are statistically independent if and only if their joint distribution equals the product of their individual marginal distributions ($f(x,y) = f_X(x) \cdot f_Y(y)$).

Quick Revision Cheat Sheet

Keep this summary handy right before your Continuous Internal Tests (CIE) and Semester End Examinations (SEE).

Core Formulas at a Glance

Total Probability Area $\int_{-\infty}^{\infty} f(x)dx = 1 \quad \text{and} \quad \sum P(x) = 1$
Expected Value (Mean $\mu$) $E[X] = \sum x \cdot P(x) \quad \text{or} \quad \int x f(x)dx$
Variance ($V[X]$) $V[X] = E[X^2] - (E[X])^2$
Binomial Properties Mean = $np$, Variance = $npq$, $q = 1-p$
Poisson Properties Mean = $\lambda$, Variance = $\lambda$, Std Dev = $\sqrt{\lambda}$
Exponential Mean Mean = $\frac{1}{\lambda}$, Variance = $\frac{1}{\lambda^2}$
